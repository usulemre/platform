# core-domain (package)

> **Phase 1.1 — Core Domain Foundation (implemented).** The asset-agnostic, technology-independent
> canonical domain model shared across every service, workflow, AI agent, and deterministic engine.
> **Pure domain only:** no business logic, no persistence, no API, no infrastructure, no AI.

## Purpose

Define the platform's **shared language** — the bounded contexts, entities, value objects,
aggregates, repository and domain-service _interfaces_, domain events, and domain errors — so every
higher layer speaks the same, governed vocabulary. Consequential decisions belong to the
deterministic engines (Architecture V2 §5.6/§6.3); this layer models the domain, it never decides.

## What is here (Phase 1.1)

- **`src/core_domain/shared/`** — the shared kernel: identities (content-addressed / versioned),
  bitemporal time (supplied, never read), the authority spine (propose/narrate/decide/approve),
  provenance, and the base patterns (`Entity`, `AggregateRoot`, `DomainEvent`, `ReadRepository` /
  `AppendOnlyRepository` / `ContentAddressedRepository` / `AsOfReadPort`, `Specification`, `Policy`,
  `Factory`, `DomainService`) plus the canonical domain errors.
- **13 bounded-context modules** — `research`, `dataset`, `experiment`, `feature`, `signal`,
  `strategy`, `portfolio`, `risk`, `validation`, `execution`, `workflow`, `agent`, `governance`.
  Each has `model.py` (value objects, entities, aggregates), `events.py`, `contracts.py`
  (repository + domain-service interfaces), `errors.py`, and a `README.md`.

### Canonical domain events

`ResearchCreated` · `ExperimentRegistered` · `DatasetValidated` · `FeatureAccepted` ·
`SignalGenerated` · `StrategyApproved` · `PortfolioConstructed` · `RiskValidated` ·
`ExecutionAuthorized` · `WorkflowCompleted` (each in its bounded context's `events.py`, alongside
supporting events).

## Purity contract (Allowed / Forbidden)

- **Allowed:** frozen dataclass value objects and events; entity/aggregate definitions; `Protocol`
  interfaces for repositories/services/specifications/policies/factories; documentation.
- **Forbidden:** business logic or algorithms; persistence, database, API, UI, or infrastructure
  code; any third-party/framework dependency; AI implementation; asset-class branching (CP-8);
  ambient time/RNG (CS-3, PIT-4) — time is a value object supplied by an injected clock; secrets
  (SEC-3). Interface methods are placeholders (`...` / `raise NotImplementedError`).

## Quality guarantees (verified)

- **Technology/framework-independent:** standard library only (`dataclasses`, `enum`, `typing`,
  `__future__`); `pyproject.toml` declares **zero** runtime dependencies.
- **Deterministic:** no ambient non-determinism anywhere in the layer.
- **Reusable & testable:** every module compiles and imports cleanly; no circular dependencies
  (each context depends only on `core_domain.shared`).
- **Architecture-compliant:** realizes the shared kernel of Architecture V2; cross-context
  references are by identity (`shared.Ref` / typed ids), never by importing another context (SE-2).

## Ownership

Accountable role: ARB / PE (with domain leads for their contexts). Architecture owner: ARB.

## Dependencies

`core_domain.shared` (innermost) only. Nothing depends inward on infrastructure; dependencies flow
toward stable abstractions (IMP-12, AV2-13); circular dependencies are PROHIBITED.
