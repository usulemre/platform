# contracts (package) — `platform_contracts`

> **Phase 1.2 — Shared Contracts Foundation (implemented).** The canonical, immutable, technology-
> independent contract layer: the formal messages exchanged between domains, services, workflows,
> AI agents, and deterministic engines. **Contracts only** — no business logic, no persistence, no
> API, no infrastructure.

## Purpose

Define the platform's **integration waist** (Architecture V2 §5.10, Contracts Spine): the stable,
versioned Commands, Queries, Events, Requests, Responses, and DTOs, plus the interface contracts
(Repository, Service), Policies, Specifications, structural Validation contracts, and Error
contracts. Consumers depend on **contracts, not implementations** (IMP-10).

## What is here (Phase 1.2)

- **`src/platform_contracts/common/`** — the contract kernel: identity references (`Id`,
  `VersionTag`, `ContentHash`, `CorrelationId`), `SchemaVersion` (versionability), the authority
  enums, the `ContractMeta` envelope (identity + version + causation + actor + supplied time), the
  base message markers (`Command`, `Query`, `Event`, `Request`, `Response`, `Dto`), the canonical
  `ErrorContract` + `ErrorCategory`, the structural `ValidationContract`, and the base
  `Policy` / `Specification` / `RepositoryContract` / `ServiceContract` patterns.
- **13 bounded-context modules** — `research`, `dataset`, `experiment`, `feature`, `signal`,
  `strategy`, `portfolio`, `risk`, `validation`, `execution`, `workflow`, `agent`, `governance`.
  Each has `messages.py` (commands/queries/requests/responses/DTOs), `events.py`, `interfaces.py`
  (repository + service + policy + specification + validation contracts), `errors.py` (error
  contracts), a per-module `SCHEMA_VERSION`, and a `README.md`.

### Canonical event contracts

`ResearchCreated` · `ExperimentRegistered` · `DatasetValidated` · `FeatureAccepted` ·
`SignalGenerated` · `StrategyApproved` · `PortfolioConstructed` · `RiskValidated` ·
`ExecutionAuthorized` · `WorkflowCompleted` (each an `Event` subclass in its context's `events.py`).

## Boundary rules (verified)

- **Immutable:** every contract is a `frozen` dataclass — runtime mutation raises
  `FrozenInstanceError`.
- **Technology/framework-independent:** standard library only (`dataclasses`, `enum`, `typing`,
  `__future__`); `pyproject.toml` declares **zero** dependencies.
- **Self-contained (stable):** depends on **nothing** — not even the domain model. Contracts are
  the stable waist; mapping between contract DTOs and `core-domain` objects happens in an outer
  anti-corruption layer, never here or in the domain (SE-2, IMP-11).
- **Deterministic:** time is supplied on the `ContractMeta` envelope, never read here (CS-3).
- **Versionable:** every message carries `schema_version`; every module carries `SCHEMA_VERSION`;
  breaking changes bump major and preserve historical artifacts (VER-1/2).
- **No business logic / persistence / API / infrastructure:** interface methods are placeholders
  (`...`); commands/queries are requests to deterministic engines — a contract never decides.

## Relationship to the contract _registry_

This package is the typed, code-level realization of the contract framework. The schema-artifact
registry (`contracts/agent_io`, `contracts/workflows`, `contracts/services`, `contracts/api`,
`contracts/domain`) and the governing frameworks (`docs/contracts/agent_contracts.md`,
`docs/contracts/workflow_contracts.md`) remain authoritative for the _rules_; this package must not
contradict them (AV2-1).

## Ownership

Accountable role: ARB (owns contracts); domain leads co-own their context's contracts.

## Dependencies

`platform_contracts.common` (innermost) only. No circular dependencies; each module depends only on
the kernel. Everything else in the platform depends on this package.

## Regeneration

Generated by [`tools/scaffolding/generate_shared_contracts.sh`](../../tools/scaffolding/generate_shared_contracts.sh)
— idempotent and auditable (IMP-7, IMP-17). Structural changes are made there and re-run.
