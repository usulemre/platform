# configuration (package) — `platform_configuration`

> **Phase 1.5 — Configuration Foundation (implemented).** The canonical, technology-independent
> abstractions for how configuration is represented, validated, versioned, and consumed across the
> platform. **Abstractions only** — no loading, no environment parsing, no secret storage, no
> persistence, no infrastructure, no business logic.

## Purpose

Define the reusable, deterministic configuration model that realizes the platform's configuration
substrate (Architecture V2 §5.10, §6.5; TDR §20 — declarative config with **secrets by reference**).
The concrete loader and secrets broker (OpenBao, per the [TDR](../../docs/architecture/technology_decision_record.md) §19/§20)
plug in **behind** these abstractions.

## What is here (Phase 1.5)

10 modules, each a subpackage with its own `README.md`:
`model` · `schema` · `metadata` · `validation` · `policies` · `versioning` · `scope` · `profiles` ·
`lifecycle` · `registry`.

Key objects: `Configuration`, `ConfigEntry`, `ConfigValue`, `SecretRef`, `ConfigurationSchema`,
`FieldSpec`, `ConfigurationMetadata`, `ConfigurationValidationResult`, `ConfigurationError`,
`ConfigurationPolicy` (+ `SecretReferencePolicy`, `ImmutabilityPolicy`, `ScopeOverridePolicy`),
`ConfigurationVersion`, `ConfigurationScope`, `ConfigurationProfile`, `ConfigurationRegistry`.

## Scopes & lifecycle

- **11 scopes** (`scope.ConfigurationScope`): Global · Platform · Application · Service · Workflow ·
  Agent · Experiment · Dataset · Environment · Deployment · Local — with broad→narrow precedence
  (narrower overrides).
- **Lifecycle** (`lifecycle.ConfigurationLifecycle`): `DRAFT → VALIDATED → APPROVED → ACTIVE →
DEPRECATED → RETIRED`, with failure states `INVALID · REJECTED · SUSPENDED`; forward chain
  enforced (skips such as `DRAFT→ACTIVE` are forbidden, fail-closed).

## Boundary rules (verified)

- **Secrets by reference, never stored:** `SecretRef` carries only a `broker_path` — there is **no
  secret-value field anywhere** in the model. A `secret` field must be a `SECRET_REF`, and the
  `LITERAL_SECRET` error / `SecretReferencePolicy` guard inlined secrets (SEC-3, CODE-29, FB-14).
- **Technology/framework-independent:** standard library + the `platform_contracts` kernel only; a
  scan confirms **no** env access, file/IO, parsing, or broker/persistence imports.
- **Deterministic:** no ambient reads; `occurred_at`/values are supplied data (CS-3).
- **Immutable & versionable:** every object is a `frozen` dataclass (runtime `FrozenInstanceError`);
  an ACTIVE configuration is superseded by a new version, never mutated (CP-2, VER-1/2).
- **Auditable:** metadata carries owner/scope/version/lifecycle; the registry is append-only.
- **No loading / env parsing / secret storage / persistence / infra:** validator, policy, and
  registry methods are `...` placeholders.
- **Compiles and imports cleanly**, 10 modules, no circular dependencies.
